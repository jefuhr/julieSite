# images

Drop your photos here with these exact names and they'll appear on the page automatically:

- `photo-1.jpg`
- `photo-2.jpg`
- `photo-3.jpg`

Until a file exists, the frame shows a dashed "photo N" placeholder instead — nothing breaks.

**Tips**
- The frames are 4:5 (portrait) and crop to fill, so portrait-ish shots look best.
- Any web format works — just update the `src` in `index.html` if you use `.png` / `.webp`.
- Want more than three? Copy one `<figure class="polaroid">` block in `index.html` and point it at `photo-4.jpg`.
